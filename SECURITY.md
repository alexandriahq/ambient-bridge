# Security Policy

Please do not file a public issue containing an exploitable vulnerability, credentials, session data, or private user content.

Report suspected vulnerabilities through a [private GitHub security advisory](https://github.com/alexandriahq/ambient-bridge/security/advisories/new). Include the affected version or commit, platform, reproduction steps, impact, and any suggested mitigation. Keep proof-of-concept data synthetic and remove secrets before attaching logs.

Ordinary bugs that do not expose a security weakness can be reported through the public issue tracker.
